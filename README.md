# Number Analysis- task5 vedatechnology
## AI & ML Internship — Python Task

A simple Python-based **Number Analysis** program that processes a list of numbers and identifies even and odd numbers, along with the largest and smallest values.

## 📌 Project Overview

This beginner-friendly Python project demonstrates basic programming concepts such as:

* Lists
* Loops
* Conditional statements
* Data comparison
* Basic numerical analysis
* Output formatting

The program takes a predefined list of numbers and generates useful insights from the data.

## 🚀 Features

The program calculates and displays:

* **Original List** — Displays the input numbers.
* **Even Numbers** — Identifies all even numbers.
* **Odd Numbers** — Identifies all odd numbers.
* **Largest Value** — Finds the highest number in the list.
* **Smallest Value** — Finds the lowest number in the list.

## 💻 How It Works

The program starts with a list of numbers and processes each value using conditional statements.

Numbers divisible by `2` are classified as **even**, while the remaining numbers are classified as **odd**.

The program then determines the largest and smallest values from the list.
